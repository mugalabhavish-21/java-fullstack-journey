# HireFlow — React Job Board

A polished, responsive React portfolio project created for a frontend interview.

## Features
- React functional components and hooks (`useState`, `useEffect`, `useMemo`)
- Search across job title, company and skills
- Location and employment-type filters
- Save jobs with `localStorage` persistence
- Apply flow with application state
- Job details modal
- Add demo job using React state
- Light/dark theme with persistence
- Responsive CSS for desktop, tablet and mobile

## Run locally
```bash
npm install
npm run dev
```

## Tech stack
React, Vite, JavaScript, CSS
